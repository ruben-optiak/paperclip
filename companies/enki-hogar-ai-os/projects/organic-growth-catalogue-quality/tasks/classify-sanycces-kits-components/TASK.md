The catalogue comparison contains 55 absent kit/configuration groups and six absent component groups. It also resolves two references, `BNCA006` and `ROC006`, as compatibility context rather than sellable rows. Publishing every catalogue reference as a standalone product would therefore create false products and broken compatibility claims.

For each kit and component, determine whether it is a sellable SKU, required bundled part, optional accessory, concealed body, compatibility-only reference or non-commercial technical context. Preserve K/KS configuration semantics and link components to compatible sellable products without inferring compatibility from proximity alone.

Acceptance requires a reviewed disposition for all 61 absent groups, source-page evidence, exact component relationships and a list of entities explicitly prohibited from standalone publication. Any approved kit must retain its component and finish evidence through the variable-product bundle.
