Define the future authoritative sources for system boundaries, deployed topology, API schemas, data models, ADRs/RFCs, threat models, SLOs, and migration history. Repositories remain disconnected in v0.1.

Done when every architectural claim type has an owner, source, freshness rule, and explicit unavailable behavior.
