Document the least-privilege, read-first requirements for future repository and PR access: exact repos, immutable revision reads, checks, comments, branch writes, merge denial, secret isolation, audit, and revocation.

Done when repository review can be enabled separately from implementation and merge authority. Do not connect a repository in this task.
